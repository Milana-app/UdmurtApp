# Удмуртский язык (UdmurtApp)

Мобильное приложение для изучения удмуртского языка для детей дошкольного и школьного возраста.

**Функционал**
- **Уроки:** Изучение слов по категориям (Семья, Еда, Природа и т.д.).
- **Словарь:** Поиск слов, озвучка, добавление в избранное.
- **Игры:** 
  - Соединение слов с переводом.
  - Выбор правильного перевода.
  - Сортировка слов по категориям.
  - Поиск лишнего слова.
  - Игра «Найди пару» (мемо).
  - Верно/Неверно
- **Слово дня:** Ежедневное новое слово с примером использования.
- **Статистика:** Отслеживание прогресса, серии дней (streak) и достижений.
- **Профиль:** Смена аватарки и имени.

**Технологии**
- Java / Android SDK
- Supabase (Backend / База данных)
